LIVE DESIRED STATE

walter-liliana

The live desired state for one Oracle Cloud development machine managed by Walter.

  • Walter
  • Oracle Cloud
  • Development machine
  • R2 state

#Overview

This deployment shares its OCI tenancy and subnet with walter-ada, and shares an R2 bucket with other deployments, remaining isolated by its profile and Walter-specific state stage. It has not been created yet: only build and dry-run have run here.

#Architecture

operator ─ SSH alias + walter-generated key ─ OCI development VM
   │                                            ├─ Nix + tools
   │                                            ├─ Its own GitHub token
   │                                            ├─ Emacs configuration
   │                                            └─ getcolors source checkouts
   └─ Walter/OpenTofu ─ R2 remote state

#Desired state

colors.yml selects OCI, the machine shape and image, editor setup, source organisations, and remote backend. It is the only normal edit.

#Safe inspection

./green build
./green create --dry-run
./green stop
./green start
ssh walter-liliana

#Operations and safety

Boot volume contains working dataDelete removes uncommitted work. Keep compute-prevent-destroy: true; never export COLORS_PAR_PROFILE. Walter generates and owns ~/.ssh/walter-liliana, and never regenerates an existing file of that name.

OCI power verbs require a current session token. Create does not automatically start a stopped machine.

#Package relationship

The root green is a copied launcher. Re-copy it after an installed skill update. Behavior and the full manual live in the Walter package repository.
